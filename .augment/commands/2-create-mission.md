# Step 2: Create Mission

> **Usage**: Reference with `.augment/commands/2-create-mission.md` or copy into chat

---

## Workflow Instructions

Now that you've gathered information about this product, use that info to create the mission document in `fabric/product/mission.md`.

### Mission Document Structure

```markdown
# [Product Name] Mission

## Vision
[One sentence describing the ultimate goal]

## Mission Statement
[2-3 sentences describing what the product does and why]

## Core Values
- [Value 1]: [Description]
- [Value 2]: [Description]
- [Value 3]: [Description]

## Target Users
[Description of primary user personas]

## Problem We Solve
[Clear articulation of the problem]

## Our Solution
[How this product addresses the problem]

## Success Metrics
- [Metric 1]
- [Metric 2]
- [Metric 3]
```

---

## Display Confirmation and Next Step

Once you've created mission.md, output the following message:

```
✅ I have documented the product mission at `fabric/product/mission.md`.

Review it to ensure it matches your vision and strategic goals for this product.

NEXT STEP 👉 Run .augment/commands/3-create-roadmap.md
```

---

## User Standards & Preferences Compliance

IMPORTANT: Ensure the product mission is ALIGNED and DOES NOT CONFLICT with the user's preferences and standards as detailed in `fabric/standards/` (if it exists).
