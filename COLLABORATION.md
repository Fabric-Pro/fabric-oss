# Collaboration & Governance

Fabric is developed in the open in this repository.

- **Contributing:** see [CONTRIBUTING.md](./CONTRIBUTING.md) — development setup,
  PR conventions, and the DCO sign-off requirement for all contributions.
- **Code of Conduct:** [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
- **Security reports:** [SECURITY.md](./SECURITY.md) — please do not open public
  issues for vulnerabilities.
- **Licensing:** Apache-2.0 for the platform core, MIT for the client packages
  (`packages/{cli,sdk,sdk-mcp,integrations-*}`); see [LICENSE](./LICENSE),
  [NOTICE](./NOTICE), and `docs/licensing.md`.

## Decision-making

Changes land by pull request with maintainer review. Substantial architectural
decisions are recorded as ADRs in `docs/adr/`. Maintainers may delegate area
ownership to consistent contributors over time.
