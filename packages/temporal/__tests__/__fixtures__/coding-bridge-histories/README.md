# Synthetic coding workflow histories

Audience: workflow maintainers. Owner: Agent & Platform team.

These histories were generated by the Temporal TypeScript SDK 1.23.0 against its
local time-skipping test server. All activities, repository preparation, database
calls and provider responses were synthetic doubles. No production history,
credentials, tenant data or provider call is included.

- `legacy-before-bridge.json`: completed workflow before the native bridge patch
  existed; retains legacy activity arguments and polling commands.
- `native-before-cutover-gate.json`: completed workflow with the original native
  bridge patch and before the default-off cutover marker existed.

Both use synthetic `example-*` identities. Payloads use the SDK JSON converter;
timestamps and command ordering are retained. The adjacent replay-cutover test
bundles the current workflow and replays both histories using `Worker.runReplayHistory`.
It also executes and replays a new default-off legacy run. Regenerate only from
the corresponding historical workflow with fake activities and the time-skipping
server; do not edit commands or patch markers to make replay pass.
