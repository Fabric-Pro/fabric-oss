DEVELOPER SCOPE  ·  DEPENDENCIES
Cross-phase dependencies to protect the roadmap
  01  Core platform → all  FND-01/02/03/06/08 must be stable before P2 pricing, inventory, ordering and P3 field workflows.
  02  Catalog → recommendations  CAT-09/10/11 and supplier data power P1 rendering and selection; CAT-12 and INT-05 extend them in P2.
  03  Design/BOM → quoting  DES-01–04 and EST-01 define the design contract consumed by EST-02–05 and QTE-03–07.
  04  Identity → transactions  INT-01/02 are prerequisites for P2 ERP, inventory, customer pricing, checkout and order submission.
  05  Supplier APIs → promos  INT-05 and CAT-10 must be available before REB-01–05 can show reliable net pricing.
  06  Transactions → projects  Approved quotes, BOMs and orders from EST/QTE/COM feed PRJ-01–05 and the homeowner dashboard.
  07  Promos → rebate ops  REB-01–05 must establish offer-to-SKU rules before claim prefill and back-end accrual in REB-06/07.
  08  Commerce → extensions  P2 ERP and commerce data precede CRM, contractor-tool and financing integrations in INT-07–09 and QTE-08.
Critical path: P1 foundations + catalog + visualization/design → P2 estimating/quote/commerce → P3 project and lifecycle features. API access and data completeness remain estimate gates.
