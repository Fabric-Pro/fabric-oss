Choosing what a repository sync reads now works the same way in Coding Instructions and Living Memory: tick the folders and files to sync in one tree, untick anything inside a ticked folder to leave it out, and read a summary of what the sync will include before saving.

Coding Instructions still syncs one folder, and unticking replaces the separate Exclude option. Living Memory can now leave out files and folders inside a selected folder, and prunes them on the next sync. Both dialogs start with nothing ticked and offer Select all and Select none, show why a row won't sync, and give a live count of the files that match.
