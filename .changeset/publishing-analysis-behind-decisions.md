A publishing topic's Planning & Analysis now says when answers have been recorded that it does not yet reflect

Fizzy #1851. Feature Maturation tells you when a decision has landed that the Full Specification has not absorbed. Publishing had the same data and said nothing: a question stores the analysis version it was raised against, so one that has since been answered while the analysis is still on that version was answered after the document was written.

The banner points at the Regenerate button already in the header rather than adding a second control that does the same thing, and it reads differently for someone who cannot regenerate — telling them the document is behind, without offering an action they do not have.
