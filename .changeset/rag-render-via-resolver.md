Test-case AI context names the same acceptance criterion the coverage ring counts

The embedded body formatted criterion references by prefixing "AC " onto whatever text a reference carried, while the coverage ring, traceability matrix and re-draft duplicate check all resolve a reference to its first integer. A reference worded "criterion 4" therefore read "Covers AC criterion 4" though the ring counted criterion 4, and a heading-text reference nothing can place read as a specific criterion the rest of the product denies exists. Rendering now resolves through the shared rule: placeable references render as their criterion, unplaceable ones render verbatim without inventing an identifier.
