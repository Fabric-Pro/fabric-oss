Say what actually happens to a code-of-conduct report instead of promising blanket confidentiality

The reporting section promised "Reports stay confidential" — wording written when conduct
reports went to a dedicated alias. That alias was never provisioned and the address now
resolves to the shared support inbox, which also receives waitlist signups and in-product
help requests, so the promise described a channel that no longer exists and nobody can
guarantee the membership of.

The replacement commits to the part the project controls: reports are handled by the
Community Moderators, details go only to the people needed to respond, and nothing is
shared more widely without the reporter's agreement except where the law requires it.
Every clause stays true if the inbox's distribution list changes, which the previous
sentence did not.

Fizzy #2352, closing the open item flagged in the first consolidation PR and deliberately
left for a separate decision: narrowing a public confidentiality commitment is a governance
call, not a side effect of repointing a mailbox. Documentation only — no code path reads
this text.
