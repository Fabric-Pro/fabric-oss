Prompt tags become one green-filled pill everywhere, and default badges are outlined and coloured by tier.

Fizzy #2068 review F3. Tags rendered four different ways across the library — per-tag hash colours in the grid and detail page, outlined badges in the list and preview — so the same tag changed appearance depending on where you saw it. All four now share one filled green pill component. The "Default · tier" badge drops its uniform green fill for an outlined style whose colour says how far up the ladder the default's authority reaches: rose for System, amber for Organization, blue for Project, green for Personal. The action catalog also splits Roadmap from Work Items, so the re-prioritisation prompts sit under the Priority view they drive instead of hiding in a fifteen-row group.
