Connect Excalidraw to Fabric AI so agents can create and edit diagrams — flowcharts, architecture sketches, and wireframes — as runtime actions.

Excalidraw is provided as an **MCP server**, added from the MCP Registry.

## Setting Up Excalidraw

<Steps>
  <Step>
    ### Open the MCP Registry

    Go to **Settings → MCP Registry** and find **Excalidraw**.
  </Step>

  <Step>
    ### Enable

    Excalidraw requires no external credentials — enable the server and it's available to agents.
  </Step>
</Steps>

### In AI Chat

```
"Draw an architecture diagram of the auth flow we discussed"
```
