---
title: Your first conversation
description: Sign in, open Genie, and ask something about the work in your organization.
---

A conversation in Fabric starts in **Genie**. The answer can use a project, connected tools, and the agents your organization has published.

<Steps>
  <Step>
    ### Sign in

    Open [fabric.pro](https://fabric.pro) and sign in. You land in your organization.
  </Step>
  <Step>
    ### Open Genie

    Choose **Genie** in the sidebar. The composer is the conversation.
  </Step>
  <Step>
    ### Ask about the work

    Ask for something your team is doing. If a project is open, Genie uses that project's context.
  </Step>
  <Step>
    ### Add a model if Genie cannot answer

    Open **Settings → AI Providers**, add a provider, and save the key. See [Configure a model](/docs/getting-started/ai-configuration).
  </Step>
</Steps>

## Where things live

| In the sidebar | What you do there |
| --- | --- |
| **Genie** | Ask, and keep the thread |
| **Projects** | Specs, coding instructions, tests, and artifacts |
| **AI Agents** | Agents the organization can run |
| **Connections** | Tools agents can call |
| **Workflows** | Work that runs on a schedule or a trigger |
