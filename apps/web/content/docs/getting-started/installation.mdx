Fabric AI offers multiple options depending on your needs.

## Cloud Hosted (Recommended)

The cloud-hosted version is the easiest way to use Fabric AI. No installation required.

<Steps>
  <Step>
    ### Sign Up

    Visit [fabric.pro](https://fabric.pro) and create your account.
  </Step>

  <Step>
    ### Configure AI Provider

    Add your API key for OpenAI, Anthropic, or other supported providers in **Settings > AI Providers**.
  </Step>

  <Step>
    ### Start Using

    You're ready to go! Create agents, upload documents, and start generating content.
  </Step>
</Steps>

**Advantages:**
- No setup or maintenance required
- Automatic updates and new features
- Enterprise-grade security and reliability
- Managed infrastructure with 99.9% uptime

---

## Self-Hosted

Fabric AI is open source and can be self-hosted for organizations that need full control over their data and infrastructure.

Self-hosting requires running the application services, a database, and storage. Detailed setup instructions, prerequisites, and environment configuration are available in the [project repository on GitHub](https://github.com/fabric-ai/fabric-portal).
