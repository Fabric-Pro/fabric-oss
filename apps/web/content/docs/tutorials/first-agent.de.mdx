---
title: Ihren ersten Agenten erstellen
description: Bauen Sie einen Agenten mit Anweisungen, Wissen und Werkzeugen, und nutzen Sie ihn in Genie.
---

Ein Agent ist ein benannter Satz von Anweisungen plus dem Wissen und den Werkzeugen, die er nutzen darf. Ihre Organisation kann ihn aus Genie heraus und in den Projekten ausführen, denen Sie ihn zuordnen.

<Callout type="idea">
  Sidekick sitzt neben dem Builder. Beschreiben Sie den Agenten, übernehmen Sie den Entwurf, und bearbeiten Sie die Anweisungen, bis sie zur Aufgabe passen.
</Callout>

<Steps>
  <Step>
    ### Den Builder öffnen

    Wählen Sie **AI Agents** und dann **Create New Agent**.

    Sie können auch unter **Templates** starten, wenn es für die Aufgabe schon einen Ausgangspunkt gibt. Eine Vorlage öffnet denselben Builder mit ausgefüllten Anweisungen.
  </Step>
  <Step>
    ### Die Anweisungen schreiben

    **Instructions** ist das erste Feld und erforderlich. Schreiben Sie, wofür der Agent da ist, was er nachschlagen soll, bevor er antwortet, und welche Form das Ergebnis haben soll.

    Ein Agent für den Wochenstatus kann so beginnen:

    ```
    You write a weekly status for this project.

    Use only the project context and the tools you were given.
    Organize the note as Accomplishments, In progress, Blockers, and Next.
    Keep it under 400 words.
    If a fact is missing, say so. Do not invent dates, owners, or numbers.
    ```
  </Step>
  <Step>
    ### Ihn benennen und sagen, wann man ihn nimmt

    Unter **Agent details**:

    - **Name**. Der Name, den Personen unter AI Agents sehen.
    - **Description**. Ein oder zwei Sätze, wann man diesen Agenten wählt.
    - **Project**, optional. Ordnen Sie ihn dem Projekt zu, dessen Kontext er bevorzugen soll.
    - **Expected output**, optional. Wie ein gutes Ergebnis aussieht, zum Beispiel eine belegte Notiz oder ein Testplan.
  </Step>
  <Step>
    ### Wissen und Werkzeuge geben

    **Knowledge & Tools** ist der nächste Abschnitt.

    - **Knowledge**. Workspaces und Integrationen, die der Agent durchsuchen darf.
    - Werkzeuge aus den Verbindungen, die Ihre Organisation schon eingerichtet hat.

    Geben Sie dem Agenten die kleinste Menge, die die Aufgabe kann. Eine engere Menge antwortet häufiger aus der richtigen Quelle.

    <Callout type="info">
      Verbindungen legen Sie unter **Connections** in der Seitenleiste an. Ein Agent kann nur ein Werkzeug nutzen, das die Organisation verbunden hat.
    </Callout>
  </Step>
  <Step>
    ### Anlegen

    Wählen Sie **Create Custom Agent**, wenn Sie bei null begonnen haben, oder **Create Agent**, wenn Sie von einer Vorlage gekommen sind.

    Starter messages, Triggers und Execution settings sind optional. Öffnen Sie sie, wenn Sie Vorschläge wollen oder einen Lauf, der durch ein Ereignis startet. Sie können das ergänzen, nachdem der Agent existiert.
  </Step>
  <Step>
    ### Ihn benutzen

    Öffnen Sie **Genie** und bitten Sie den neuen Agenten um die Aufgabe, die Sie aufgeschrieben haben, oder öffnen Sie den Agenten unter **AI Agents** und starten Sie dort.

    Wenn die Antwort eine Quelle ignoriert, gehen Sie zurück in den Builder, engen Sie **Knowledge & Tools** ein und schärfen Sie die Anweisungen.
  </Step>
</Steps>
