---
title: Create your first agent
description: Build an agent with instructions, knowledge, and tools, then use it from Genie.
---

An agent is a named set of instructions plus the knowledge and tools it may use. Your organization can run it from Genie and from the projects you attach it to.

<Callout type="idea">
  Sidekick sits beside the builder. Describe the agent you want, apply the draft it proposes, and edit the instructions until they match the job.
</Callout>

<Steps>
  <Step>
    ### Open the builder

    Choose **AI Agents**, then **Create New Agent**.

    You can also start from **Templates** when the job already has a starting point. A template opens the same builder with instructions filled in.
  </Step>
  <Step>
    ### Write the instructions

    **Instructions** is the first field, and it is required. Say what the agent is for, what it should look up before it answers, and the shape of the result.

    A weekly status agent can start from:

    ```
    You write a weekly status for this project.

    Use only the project context and the tools you were given.
    Organize the note as Accomplishments, In progress, Blockers, and Next.
    Keep it under 400 words.
    If a fact is missing, say so. Do not invent dates, owners, or numbers.
    ```
  </Step>
  <Step>
    ### Name it and say when to use it

    Under **Agent details**:

    - **Name**. The name people see in AI Agents.
    - **Description**. One or two sentences on when to choose this agent.
    - **Project**, optional. Attach it to the project whose context it should prefer.
    - **Expected output**, optional. What a good result looks like, such as a cited note or a test plan.
  </Step>
  <Step>
    ### Give it knowledge and tools

    **Knowledge & Tools** is the next section.

    - **Knowledge**. Workspaces and integrations the agent may search.
    - Tools from the connections your organization has already set up.

    Give the agent the smallest set that can do the job. A narrower set answers from the right source more often.

    <Callout type="info">
      Connections are added under **Connections** in the sidebar. An agent can only use a tool the organization has connected.
    </Callout>
  </Step>
  <Step>
    ### Create it

    Choose **Create Custom Agent** when you started from scratch, or **Create Agent** when you started from a template.

    Starter messages, triggers, and execution settings are optional. Open them when you want suggested prompts, or a run that starts from an event. You can add them after the agent exists.
  </Step>
  <Step>
    ### Use it

    Open **Genie** and ask the new agent for the job you wrote down, or open the agent from **AI Agents** and start there.

    If the answer ignores a source, return to the builder, narrow **Knowledge & Tools**, and tighten the instructions.
  </Step>
</Steps>
