Dieses Tutorial führt Sie durch die Erstellung Ihres ersten Dokuments mit Fabric AI. In etwa 10 Minuten gelangen Sie von einer groben Idee zu einem ausgefeilten PRD.

## Was Sie erstellen werden

Am Ende dieses Tutorials haben Sie:

- Einen Workspace mit Referenzdokumenten erstellt
- Ein Gespräch mit dem Document Generator-Agenten begonnen
- Ein vollständiges PRD (Produktanforderungsdokument) generiert
- Gelernt, wie Sie Ihr Dokument verfeinern und exportieren

## Voraussetzungen

Stellen Sie sicher, dass Sie folgendes haben:

- ✅ Ein Fabric AI-Konto ([hier registrieren](https://fabric.pro))
- ✅ Einen konfigurierten KI-Anbieter (siehe [KI-Konfiguration](/docs/getting-started/ai-configuration))
- ✅ 10 Minuten Zeit

## Schritt 1: Kontext vorbereiten (Optional)

Wenn Sie vorhandene Dokumente haben, auf die die KI verweisen soll, erstellen Sie zunächst einen Workspace:

<Steps>
  <Step>
    ### Zu Workspaces navigieren

    Klicken Sie in der linken Seitenleiste auf **Workspaces**.
  </Step>

  <Step>
    ### Einen neuen Workspace erstellen

    Klicken Sie auf **Workspace erstellen** und geben Sie ihm einen Namen wie „Produktdokumentation".
  </Step>

  <Step>
    ### Dokumente hochladen

    Legen Sie alle Referenzmaterialien per Drag-and-Drop ab:
    - Frühere PRDs
    - Unternehmensvorlagen
    - Technische Einschränkungen
    - Marktforschung

    Haben Sie keine? Kein Problem — fahren Sie mit Schritt 2 fort!
  </Step>
</Steps>

## Schritt 2: Ein Projekt starten

<Steps>
  <Step>
    ### Zu Projekten navigieren

    Klicken Sie in der linken Seitenleiste auf **Projekte**.
  </Step>

  <Step>
    ### Neues Projekt erstellen

    Klicken Sie auf **Projekt erstellen** und füllen Sie aus:

    - **Name**: „Mein erstes Feature"
    - **Beschreibung**: „Fabric AI kennenlernen"
  </Step>

  <Step>
    ### Projekt öffnen

    Klicken Sie auf Ihr neues Projekt, um es zu öffnen.
  </Step>
</Steps>

## Schritt 3: Ihr Dokument generieren

Jetzt kommt der spannende Teil — lassen Sie uns ein PRD generieren!

<Steps>
  <Step>
    ### Ein Gespräch beginnen

    Klicken Sie auf **Neues Dokument** oder die **Chat**-Schaltfläche in Ihrem Projekt.
  </Step>

  <Step>
    ### Kontext anhängen (Optional)

    Wenn Sie einen Workspace erstellt haben:
    1. Klicken Sie auf die **Anhängen**-Schaltfläche (Büroklammer-Symbol)
    2. Wählen Sie Ihren Workspace
    3. Die KI verweist nun auf diese Dokumente
  </Step>

  <Step>
    ### Ihr Feature beschreiben

    Geben Sie eine Beschreibung dessen ein, was Sie bauen möchten. Hier ein Beispiel:

    ```
    Erstelle ein PRD für eine Funktion zur Verwaltung von Benachrichtigungseinstellungen.

    Die Funktion sollte Benutzern ermöglichen:
    - Zu wählen, welche Arten von Benachrichtigungen sie erhalten
    - Ihren bevorzugten Benachrichtigungskanal auszuwählen (E-Mail, Push, SMS)
    - Ruhezeiten festzulegen, in denen sie nicht gestört werden möchten
    - Benachrichtigungshäufigkeit anzupassen (sofort, tägliche Zusammenfassung, wöchentlich)

    Zielbenutzer: Kostenlose und Premium-Benutzer
    Plattform: Web- und mobile Apps
    ```

    Drücken Sie Enter zum Senden.
  </Step>

  <Step>
    ### Die Magie beobachten

    Der Document Generator wird:
    1. Ihre Anfrage analysieren
    2. Relevanten Kontext abrufen (wenn angehängt)
    3. Ein umfassendes PRD generieren
    4. Die Ausgabe in Echtzeit streamen

    Dies dauert normalerweise 30-60 Sekunden.
  </Step>
</Steps>

## Schritt 4: Überprüfen und verfeinern

Ihr PRD ist generiert! Jetzt machen wir es perfekt.

### Die Ausgabe verstehen

Das generierte PRD enthält typischerweise:

- **Zusammenfassung** — Überblick auf hoher Ebene
- **Problemstellung** — Warum dieses Feature benötigt wird
- **Ziele und Objektive** — Wie Erfolg aussieht
- **User Stories** — Als/Ich will/Damit-Format
- **Anforderungen** — Funktionale und nicht-funktionale
- **Erfolgsmetriken** — Wie Erfolg gemessen wird
- **Zeitplan** — Vorgeschlagene Phasen

### Änderungen vornehmen

Sie haben mehrere Optionen:

**Option 1: Mit dem Agenten chatten**

Bitten Sie um spezifische Änderungen:

```
„Füge einen Abschnitt über Sicherheitsaspekte hinzu"

„Erweitere den Abschnitt User Stories mit mehr Randfällen"

„Mache den Zeitplan aggressiver — wir brauchen das in 6 Wochen"
```

**Option 2: Direkt bearbeiten**

Klicken Sie in das Dokument und bearbeiten Sie es wie in einem Texteditor:
- Abschnitte hinzufügen oder entfernen
- Bestimmte Absätze umschreiben
- Tippfehler oder Formatierung korrigieren

**Option 3: Änderungen annehmen/ablehnen**

Wenn die KI Änderungen vorschlägt:
- **Annehmen** — Änderungen übernehmen
- **Ablehnen** — Ihr Original behalten
- **Mit Anpassungen annehmen** — Als Ausgangspunkt verwenden

## Schritt 5: Ihr Dokument exportieren

Wenn Sie mit Ihrem PRD zufrieden sind:

<Steps>
  <Step>
    ### Dokument speichern

    Klicken Sie auf **Speichern**, um es in Ihrem Projekt zu speichern.
  </Step>

  <Step>
    ### Exportieren

    Klicken Sie auf **Exportieren** und wählen Sie Ihr Format:
    - **Markdown** — Für GitHub, Notion usw.
    - **PDF** — Zum Teilen und Drucken
    - **DOCX** — Für Microsoft Word
  </Step>

  <Step>
    ### Teilen (Optional)

    - Einen teilbaren Link kopieren
    - Direkt aus Fabric per E-Mail senden
    - An Slack oder Teams posten
  </Step>
</Steps>

## Tipps für bessere Ergebnisse

### Spezifisch sein

```
❌ „Erstelle ein PRD für Benachrichtigungen"

✅ „Erstelle ein PRD für eine Benachrichtigungseinstellungs-Funktion, die Benutzern
   ermöglicht, E-Mail-, Push- und SMS-Benachrichtigungen separat zu steuern,
   mit Ruhezeiten und Häufigkeitseinstellungen"
```

### Kontext bereitstellen

Je mehr Kontext Sie bereitstellen, desto besser die Ausgabe:

- Relevante Workspaces anhängen
- Bestehende Einschränkungen erwähnen
- Auf ähnliche Features verweisen
- Zielbenutzer spezifizieren

### Folgefragen nutzen

Versuchen Sie nicht, alles in einer Anfrage perfekt zu bekommen:

```
Zuerst: „Erstelle ein PRD für Benutzerbenachrichtigungen"
Dann:   „Füge mehr Details zu den mobilen App-Anforderungen hinzu"
Dann:   „Füge API-Spezifikationen für das Backend-Team hinzu"
```

### Iterieren

Ihr erster Entwurf ist nur der Anfang. Die besten PRDs entstehen durch:
1. Ersten Entwurf generieren
2. Mit dem Team überprüfen
3. Auf Basis von Feedback verfeinern
4. Aktualisieren, wenn Sie mehr erfahren

## Fehlerbehebung

### „Die Ausgabe entspricht nicht meinen Erwartungen"

- Seien Sie in Ihrer Anfrage spezifischer
- Hängen Sie mehr Kontextdokumente an
- Teilen Sie Ihre Anfrage in kleinere Teile auf
- Versuchen Sie einen anderen Dokumenttyp

### „Das Dokument ist zu kurz/lang"

Bitten Sie um Anpassungen:
- „Erweitere den Anforderungsabschnitt mit mehr Details"
- „Fasse dies in einer einseitigen Zusammenfassung zusammen"

### „Die KI hat Annahmen getroffen, mit denen ich nicht einverstanden bin"

Klären Sie in Folgefragen:
- „Tatsächlich unterstützen wir noch kein Mobilgerät — für nur Web aktualisieren"
- „Wir richten uns an Enterprise-Benutzer, nicht an Verbraucher"
