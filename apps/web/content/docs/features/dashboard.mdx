The Dashboard is your home screen in Fabric AI. It provides a real-time overview of your work across projects, agents, documents, and conversations.

## Overview

When you sign in, the Dashboard shows:

- **Personalized greeting** with your name
- **Key metrics** across all your work
- **Activity timeline** of recent changes
- **Quick actions** to jump into common tasks

## Metrics

Four summary cards provide at-a-glance status:

| Metric | What It Shows |
|--------|---------------|
| **Projects** | Total projects, active count, draft count |
| **Agent Tasks** | Total tasks, running count, completed count |
| **Documents** | Total documents, ready count, processing count |
| **AI Chats** | Total conversation count |

### Time Range Filter

Filter metrics by time period:

- **Today** — Activity from the current day
- **Last 7 days** — Weekly summary
- **Last 30 days** — Monthly summary
- **Last 90 days** — Quarterly summary
- **All time** — Complete history

## Activity Timeline

The activity feed shows recent updates across all your work:

- **Project updates** — New projects created, settings changed
- **Document activity** — Documents generated, edited, or processed
- **Agent tasks** — Tasks started, completed, or failed
- **Prompt changes** — Prompts created or modified

Each activity entry shows the action, timestamp, and a link to the relevant item.

## Activity Breakdown

A visual chart shows the distribution of your content:

- Projects
- Documents
- Agent tasks
- Conversations
- Workflows

This helps you understand where you spend most of your time and identify areas that may need attention.

## Agent Tasks

The Dashboard includes a table of recent agent tasks:

- **Task name** and associated agent
- **Status** — Running, Completed, Failed
- **Duration** and timestamps
- Click to view full task details

## Quick Actions

Jump directly into common tasks:

- Create a new project
- Start a chat conversation
- Browse agent templates
- Open workflow builder

## Multi-Tenant Context

The Dashboard automatically adapts to your current context:

- **Personal** (`/app`) — Shows your personal projects, chats, and tasks
- **Organization** (`/app/{org}`) — Shows organization-scoped data visible to you

Switch between contexts using the organization selector in the navigation.
